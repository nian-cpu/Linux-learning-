# Linux 学习资源库（Linux Learning Resources）

整理 Linux 学习过程中值得收藏的官方文档、技术手册和学习资料。

本目录主要用于收藏优质学习资源，方便后续查阅和系统学习。

---

## 1. Ubuntu 官方文档（Ubuntu Documentation）

<badge>核心学习资料</badge>

### 1.1 Ubuntu 官方文档总入口

* **网址：** https://docs.ubuntu.com/
* **类型：** 官方技术文档
* **内容：** Ubuntu 各个版本、桌面系统、服务器及开发环境的官方文档。

### 1.2 Ubuntu Desktop 官方文档

* **网址：** https://ubuntu.com/desktop/docs/en/latest/
* **学习内容：**

  * Ubuntu 桌面系统介绍
  * 系统安装与升级
  * 软件安装与卸载
  * 终端使用
  * 系统设置
  * 远程访问与安全管理

### 1.3 Linux 命令行入门（适合初学者）

* **网址：** https://ubuntu.com/desktop/docs/en/26.04/tutorial/the-linux-command-line-for-beginners/
* **学习内容：**

  * 如何打开和使用终端
  * 如何理解 Linux 命令
  * 文件和目录操作
  * 命令组合
  * 管理员权限（sudo）

**推荐理由：** 适合 Linux 零基础学习者，可以作为 Linux 命令行的第一份入门资料。

### 1.4 Ubuntu Server 官方文档

* **网址：** https://ubuntu.com/server/docs/
* **学习内容：**

  * Linux 终端与 Shell
  * 文件和目录管理
  * 命令行深入学习
  * 软件包管理
  * 网络配置与 DNS
  * 用户权限
  * 防火墙与系统安全

**推荐理由：** 适合进一步学习 Linux 系统管理和服务器相关知识。

## 2. Linux 官方技术手册（Technical References）

### 2.1 GNU Bash Reference Manual

* **网址：** https://www.gnu.org/software/bash/manual/
* **维护组织：** GNU Project
* **学习内容：**

  * Shell 与 Bash 基础
  * 命令执行机制
  * 变量与环境变量
  * 输入输出重定向
  * 管道（Pipeline）
  * 条件判断与循环
  * Shell 脚本编程

**推荐理由：** 学习 Bash Shell 和 Shell 脚本的重要参考手册。

### 2.2 Linux Kernel Documentation

* **网址：** https://docs.kernel.org/
* **维护组织：** Linux Kernel Community
* **学习内容：**

  * Linux 内核架构
  * 进程调度
  * 内存管理
  * 设备驱动
  * 文件系统实现

**推荐理由：** 用于深入理解 Linux 内核工作原理，适合进阶阶段阅读。

## 3. 学习顺序建议（Learning Path）

| 学习阶段 | 推荐资料              | 学习目标         |
| ---- | ----------------- | ------------ |
| 入门阶段 | Ubuntu Desktop    | 认识 Linux 和终端 |
| 基础阶段 | Linux 命令行入门       | 掌握常用命令       |
| 进阶阶段 | Ubuntu Server     | 学习系统管理       |
| 深入阶段 | GNU Bash Manual   | 理解 Shell 和脚本 |
| 高级阶段 | Linux Kernel Docs | 理解内核工作原理     |

## 4. 资源收藏原则（Notes）

* 优先收藏官方文档和权威技术手册。
* 记录每个网站的用途和适合的学习阶段。
* 学习过程中发现有价值的资料，可以继续补充。
* 尽量记录原始资料链接，方便后续查阅。
